# ClaimLens v2 - 약제 청구심사 지원 시스템

병원 청구심사 담당자를 위한 약제 검색 + 공공 API 실시간 연동 + 적응증 기반 상병코드 자동 표시 시스템입니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 약제 검색 | 약품명·성분명·급여코드 검색 |
| 상병코드 자동 매핑 | 적응증 텍스트 → KCD 상병코드 자동 표시 |
| 상병코드 직접 검색 | HIRA 질병정보 API 실시간 조회 |
| 약가 실시간 조회 | HIRA 약가기준정보 API 연동 |
| 효능/용법/주의/금기 | 식약처 허가정보 + e약은요 API 연동 |
| AI 보조 검토 | OpenAI 기반 상병·용법 검토 메모 |
| 검색 순위 | 실시간/주간/월간 집계 |
| 관리자 업로드 | JSON 형식 약제 데이터 추가·갱신 |

## 실행

```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```

## API 키 설정

`.streamlit/secrets.toml` 파일을 생성하고 아래와 같이 설정:

```toml
HIRA_API_KEY   = "공공데이터포털_HIRA_인증키"
MFDS_API_KEY   = "공공데이터포털_식약처_인증키"
ADMIN_PASSWORD = "관리자비밀번호"
OPENAI_API_KEY = ""   # 선택사항
```

## 주의사항

- API 키 없이도 로컬 DB 데이터로 기본 동작합니다.
- 상병코드 자동 매핑은 적응증 키워드 기반이며, 의무기록 근거로 최종 확인이 필요합니다.
- 운영 전 HIRA/MFDS 공식 자료와 심사 전문가 검수를 반드시 반영하십시오.

# ClaimLens - 약제 심사 지원 Streamlit 앱

병원 청구심사 담당자가 약품명, 성분명, 급여코드로 검색하고 상세 근거를 한 화면에서 검토하도록 만든 Streamlit 프로토타입입니다. `씨엠쿨산` 예시 데이터, 상병 후보 검토, 용법용량 AI 보조 연결 지점, 검색 순위, 관리자 전용 데이터 업로드를 포함합니다.

## 실행

```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 `씨엠쿨산`을 검색하고 `상세 보기`를 누르면 하단 연속 보고서가 표시됩니다.

## 관리자 및 AI 설정

운영 서버에서 환경변수 또는 Streamlit secrets를 설정하십시오.

```toml
ADMIN_PASSWORD = "충분히-긴-관리자-비밀번호"
OPENAI_API_KEY = "선택사항"
OPENAI_MODEL = "gpt-4.1-mini"
```

- `ADMIN_PASSWORD`가 없으면 관리자 업로드 기능은 비활성화됩니다.
- `OPENAI_API_KEY`가 없으면 상병/용법용량 화면은 저장된 근거 및 규칙 기반 후보만 표시합니다.
- AI 출력은 심사 결론이나 처방 판단이 아니라 확인할 자료를 정리하는 보조 메모로만 사용됩니다.

## 데이터 적재

초기 실행 시 `seed_data.json`이 로컬 SQLite 데이터베이스 `data/review_assist.db`에 적재됩니다. 관리자는 앱의 `관리자` 메뉴에서 동일한 구조의 JSON 파일을 업로드해 약제 자료를 추가 또는 갱신할 수 있습니다.

운영 전에는 다음 연계를 권장합니다.

| 목적 | 기준 출처 |
| --- | --- |
| 허가사항, 효능효과, 용법용량, 주의·금기 | 식품의약품안전처 의약품 허가정보 또는 검증된 연계 데이터 |
| 급여코드, 상한금액, 적용일 | 건강보험심사평가원 약가기준정보조회서비스 |
| 약제 심사기준, 고시 | 건강보험심사평가원 약제기준정보 |
| 금기 및 투약이력 안전 점검 | 건강보험심사평가원 DUR/기관 EMR 연계 결과 |
| 상병코드 | 최신 KCD 및 의무기록 근거 |

## 안전 및 운영 유의사항

- 샘플 자료는 화면/업무흐름 구현용이며 최신 급여 인정 결과를 확정하지 않습니다.
- 순위 집계 로그에는 선택된 약제 ID·약제명·시간만 사용하며 검색어 원문이나 환자정보를 저장하지 않도록 설계했습니다.
- 운영 배포 전 관리자 인증을 기관 SSO 또는 별도 인증 계층으로 강화하고, 업로드 감사로그와 자료 검수·개정 이력을 추가해야 합니다.
- 참고 서비스의 콘텐츠·디자인을 복제하지 않고, 심사 지원 리포트 중심의 독자적인 정보구조와 시각 디자인을 사용했습니다.
